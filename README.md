# Raphragrance

> An Independent Luxury Fragrance Encyclopedia and Olfactory Archive

Raphragrance is a comprehensive fragrance intelligence platform and digital archive showcasing over **131,000+ curated fragrances** from historic perfume houses to contemporary niche ateliers. 

Designed with an editorial aesthetic and a performance-driven foundation, Raphragrance offers perfume enthusiasts and collectors an uncompromised space to discover, study, and appreciate the art of perfumery without the noise of commercial marketplaces.

---

## What is Raphragrance?

Raphragrance serves as a modern digital reference library for fine fragrance, combining deep sensory data with an intuitive catalog interface:

- **Comprehensive 131k+ Fragrance Archive**  
  Detailed fragrance profiles spanning decades of olfactory creations, complete with release years, collections, perfumer credits, and bottle imagery.

- **Olfactory Anatomy & Note Pyramids**  
  Deconstructed scent architectures detailing top, heart, and base notes alongside proportional accord breakdowns.

- **Intelligent Contextual Search**  
  A natural language discovery engine capable of parsing combined inquiries such as brand, season, and time of day (for example: summer citrus scents, evening gourmands, or winter woods).

- **Community Olfactory Metrics**  
  Aggregated ratings covering longevity, sillage projection, seasonal resonance, and day versus night suitability.

- **Editorial Luxury Interface**  
  A bespoke, dark-mode-first aesthetic crafted with restrained typography, fluid micro-interactions, and a dedicated mobile catalog experience.

---

## Technical Foundation

Raphragrance is engineered as a unified, full-stack application built for sub-second catalog exploration across massive datasets:

- **Frontend**: Next.js with TypeScript and responsive layout architecture.
- **Data Engine**: High-throughput REST API with pre-indexed local data architecture.
- **Design System**: Tailored CSS tokens inspired by luxury fashion ateliers.
